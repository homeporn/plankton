# ПЛАНКТОН. Закрытый демонстрационный стенд

В этом архиве находятся исходники приложения, 13 миграций SQLite и профиль Docker Compose. Демонстрационный стенд рассчитан на синтетические данные и закрытый вход. В приложении отсутствуют учётные записи, роли и права на объекты, табели и начисления.

На новой Linux VM подготовьте постоянный локальный диск и доступ по SSH. Установите Docker Engine 28+ с Compose v2.20.2+, OpenSSL, curl и Bash. Скопируйте `.env.example` в `.env`, задайте отдельные абсолютные каталоги и UID/GID оператора. Запустите подготовку ключей, сборку и проверку сервера из корня распакованного каталога.

```sh
./deploy/scripts/ops.sh init
./deploy/scripts/ops.sh build
./deploy/scripts/ops.sh start
```

Проверить схему безопасности, настройки SSH-туннеля, сертификат и данные для входа, команды резервирования, восстановления и отката можно в инструкции развёртывания в корне поставки по пути `docs/v2_yandex_cloud_deployment.md`.
