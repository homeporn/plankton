# ПЛАНКТОН. Учёт рабочего времени 2.0

## Исходная точка и изоляция

- Исходный commit — `51f9a796c976826c3c1ab304c6382aea31c4ea78`, ветка `main` репозитория `homeporn/construction-progress`. В среде отсутствовала указанная стабильная локальная рабочая копия. В качестве исходной точки по согласованию взята версия из GitHub. Состояние файлов на машине стабильной установки из этой среды неизвестно.
- Изолированная ветка — `feature/plankton-ux-v2`, Git worktree — `/workspace/plankton-time-v2`. Ссылка локальной копии `main` указывает на исходный commit. Проверки и разработка использовали отдельные файлы и синтетические данные.
- Локальное окружение — `.venv` рабочего дерева. Демонстрационная SQLite лежит в `data/v2/demo.sqlite3`, рядом находятся отдельные каталоги конфигурации, логов, экспортов, резервирования и временных файлов. Для локальной приёмки использован loopback-порт 5182, браузерные проверки и Compose использовали другие порты с собственной БД.
- Проверены 13 SQL-миграций и отсутствие изменений в `migrations/`, `app/calculation_engine/`, `app/services/`, `app/repositories/` и платформенных launcher. Модель данных и расчётные правила сохранены.

## Изменения

Сводка выбранного объекта показывает шесть быстрых действий, очередь нарядов, табелей и расчётных периодов, нераспределённые часы, последние записи и готовность по направлениям. Переход к историческому срезу оставляет соответствующие дате показатели и события. Короткая форма факта и подтверждения определяет контекст по выбранной работе. В наряде используются прямой выбор позиции, сохранение черновика, отдельная выдача и явные статусные операции. Из матрицы табеля открывается массовый ввод на выбранную дату. Вид объёма переключается с сохранением фильтров. В начислениях видны источники и следующий доступный шаг, история использует сохранённые версии.

Переданный Plankton Brand Kit 0.1.0 применён через общие компоненты, две темы и локальные шрифты. Утверждённые SVG-файлы в комплекте отсутствуют. Интерфейс использует текстовое название.

## Поставка и границы допуска

Архив для ручной передачи — `/workspace/output/plankton-time-cloud.tar.gz`. Он содержит приложение Flask, миграции, локальные ресурсы бренда, Compose, WSGI Waitress, прокси nginx, процедуры резервирования и инструкцию. Постоянные данные лежат вне образа. Развёртывание рассчитано на отдельный демостенд с синтетическими данными, постоянным диском, loopback-привязкой, TLS, отдельным паролем прокси и SSH-туннелем. Подготовка ВМ, обновление и восстановление описаны в инструкции. [Развёртывание Yandex Cloud и восстановление](v2_yandex_cloud_deployment.md)

Уровень подтверждения — локальный Docker. ВМ Yandex Cloud, сборка Windows EXE, macOS-пакет и испытания в Safari для этой версии не выполнялись. В коде отсутствует этап 4.6 с учётными записями и ролями. Для публичной и многопользовательской эксплуатации требуется реализация авторизации и проверка ограничений доступа к объектам, документам, табелям, персональным данным и начислениям.
