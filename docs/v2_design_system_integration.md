# Дизайн-система «ПЛАНКТОН» в v2

Источник визуального оформления — переданный владельцем Plankton Brand Kit 0.1.0. Скомпилированный CSS и два файла DejaVu Sans скопированы в `app/web/static/brand-kit/` в исходном виде. К шрифтам приложена исходная лицензия. JSON с палитрой, темами и типографикой, руководство и манифест знака сохранены в [v2_brand_sources](v2_brand_sources/).

| Роль | Светлая тема | Тёмная тема |
|---|---|---|
| Фон | `brand.milk` | `brand.deep` |
| Поверхность | `brand.sage` | `brand.forest` |
| Текст | `brand.deep` | `brand.milk` |
| Основное действие | `brand.forest` | `brand.sage` |
| Текст на основном действии | `brand.milk` | `brand.deep` |

`v2.css` связывает роли из комплекта с CSS-переменными приложения. Границы, вторичные подписи и фоны состояний используют рассчитанные смеси исходных цветов. Адаптер задаёт смеси готовыми значениями sRGB для совместимости с Safari 13. Статусы подписаны текстом, сообщения форм связаны с полями. Интервалы 4–24 px, радиусы 6–8 px и минимальная высота поля 36 px взяты из существующего интерфейса. Типографика использует DejaVu Sans 400/700 и шкалу поставки. Шрифты загружаются с того же сервера.

В шапке доступен выбор системного, светлого и тёмного режима. Системный режим реагирует на смену настройки ОС. Выбор сохраняется в браузере и синхронизируется между вкладками. Режим печати наряда остаётся светлым. Ресурсы входят в Docker-дистрибутив и в манифест сборки Windows.

## Компоненты

- Меню, контекст объекта, сводка, карточки, кнопки, поля, фильтры, таблицы, вкладки, ошибки, пустые состояния и фокус используют общие роли. Широкие таблицы прокручиваются внутри своей области, которая получает имя и точку входа с клавиатуры.
- Сохранены специфические стили сетки табеля, замороженных столбцов, просмотра результатов и печати наряда. Шаблоны и JavaScript сохраняют серверную валидацию и нативные элементы управления.
- Манифест знака имеет статус `awaiting-approved-svg` и шесть пустых вариантов. В интерфейсе используется текстовое название приложения. Временный SVG из комплекта остаётся иллюстрацией для предпросмотра.

## Проверка

Chromium проверяет семь маршрутов при реальном масштабе 100%, 150% и 200%, ширину 390 px, длинное кириллическое название объекта, светлую и тёмную темы, высокий контраст, фокус и горизонтальную прокрутку табеля стрелками. Подтверждена загрузка обоих начертаний. При превышении доступного объёма форма показывает ошибку рядом с полями и сохраняет введённый объём и документ.

В Linux можно повторить проверку через `python tests/browser_v2_visual.py --output /tmp/plankton-visual` с зависимостями приложения, Playwright и Chromium. Safari и Windows проверялись на уровне совместимости исходников и пакета ресурсов. Протокол и снимки приведены в [v2_visual](v2_visual/).
